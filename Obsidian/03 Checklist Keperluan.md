# Checklist Keperluan

[← Beranda](00%20Mulai%20di%20Sini.md)

Checklist manual. Kotak kosong berarti **belum dikonfirmasi dalam catatan**, bukan kepastian bahwa belum dikerjakan. Centang setelah ada bukti.

## Pendaftaran individu — guidebook hlm. 7
- [ ] Akun peserta di portal panitia.
- [ ] Bukti identitas mahasiswa/pelajar (KTM/lainnya).
- [ ] Bukti post Twibbon.
- [ ] Bukti share poster lomba di Instagram Story.
- [ ] Bukti follow Instagram `sevent.tup`.
- [ ] Bergabung Discord SEVENT X dan melengkapi username Discord.

## Tim — hlm. 6–8
- [ ] Nama tim dan ketua ditentukan.
- [ ] Anggota 3–5 orang, semuanya satu institusi dan memenuhi syarat.
- [ ] Ketua membuat tim Software Development; anggota bergabung dengan Team Code.
- [ ] Pembayaran Rp80.000 per tim selesai dan bukti diunggah.

## Produk — pilih kategori, hlm. 10–13
**Website:**
- [ ] URL online aktif dan bisa diakses; fitur inti berfungsi dan responsif.

**Mobile:**
- [ ] APK bisa diinstal dan diuji; IPA opsional untuk iOS.

## Berkas submission bersama — hlm. 10–13
- [ ] Satu karya dan satu proposal.
- [ ] Repository GitHub publik dan aktif selama lomba.
- [ ] Template proposal resmi diperoleh.
- [ ] Proposal sesuai struktur template; batas 25 halaman dipenuhi, di luar cover/daftar pustaka/lampiran.
- [ ] Surat pernyataan orisinalitas memakai template panitia.
- [ ] Video demo YouTube maksimal 5 menit.
- [ ] Judul video sesuai `Nama Tim | SoftDev - SEVENT X National Competition`.
- [ ] Produk dan seluruh tautan diuji dari perangkat/browser lain.
- [ ] Hasil karya diunggah dan benar-benar disubmit di portal.
- [ ] Bukti/status submission berhasil disimpan.

## Catatan bukti
Isi ketika tersedia; jangan menyimpan password, token, atau dokumen identitas sensitif di vault ini.
